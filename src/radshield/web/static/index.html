    Isotope library

    Physical constants and per-material Archer broad-beam fit (alpha, beta in 1/cm; gamma dimensionless) for every isotope a TG-108-style source can use. Built-in TG-108 values can be edited and reset back to the shipped default. A new isotope's Archer fields start out copied from the 511 keV fit — the one shielding dataset this app ships — as a starting point; overwrite them with isotope-specific data when you have it, and record where it came from.
